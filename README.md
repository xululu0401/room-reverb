# 房间的混响时间

把房间的长宽高和六个面的材料填进去，算清三件事：**这个房间会把声音拖多久**（各频段混响时间 RT60）、
**低频在哪些频率上堆起来**（轴向驻波 / 房间模式）、**要补多少等效吸声量、等于多少 m² 的什么材料**
才能把混响压到你定的目标值。全部在浏览器本地算：不联网、不测量、不读图纸、不内置任何产品参数。

## 开发

```
node build.cjs                 # template.html + core.js + ui.js → index.html
node --test tests/core.test.cjs # 核心测试（63 项）
node 说明数字校验.cjs            # 说明.txt 里每个数字回溯到引擎运行 / 常量
node 对照锚点.cjs               # 与独立 Python 实现（Decimal 40 位）逐项对拍
node 验收脚本.cjs --tag 本地      # 浏览器验收 93 项断言（真实浏览器，本地）
```

本地服务：`python3 -m http.server 8823`（`file://` 也能跑，导出与持久化都验证过）。

## 架构

- `core.js` —— 纯函数引擎（几何 → 吸声量 → RT60 → 驻波 → 单点指标 → 反解 → 自检），浏览器与 node 通用，
  挂到 `window.AppCore`。
- `ui.js` —— 界面层：三步向导 + 房间声学体检报告 + 四种导出。页面上的每个数字都来自同一次 `compute()`。
- `template.html` —— 骨架与样式（`build.cjs` 把 core/ui 内联进 `index.html`，单文件交付）。
- `tests/core.test.cjs` —— 核心测试：手算锚点、独立朴素实现对拍、不变量、非法输入、自检反向验证。

## 公式（与页面数字同一套）

```
V         = L · W · H
A_band    = Σ(面面积 × 该面材料在该频段的吸声系数) + 家具等效吸声 + 吸声板
RT60      = 0.161 · V / (A + 4mV)          （m 为空气吸收系数，只有 2k/4k 段非零）
驻波 f     = (343/2) · √((nx/L)² + (ny/W)² + (nz/H)²)
Schroeder = 2000 · √(RT60₅₀₀ / V)
临界距离   = 0.141 · √(Q · A)               （Q = 1）
A_target  = 0.161 · V / RT60_target
```

## 口径与边界（写清楚了才敢用）

- 统计声学（Sabine）假设声场扩散、各表面吸声均匀；小房间、强吸收、低频下都不严格成立，
  所以 **RT60 是模型输出、不是实测值**。
- 只支持长方体；墙面面积按净空几何算（**不减门窗洞**）；吸声板**不扣**被它遮住那部分墙面的原吸声量
  —— 后两处都是保守口径。
- 驻波只列**轴向**模式（下标里只有一个非零，各阶不超过 4 阶、只到 300 Hz）；一条模式 = 一个互不相同的
  下标组合，表格按频率归并显示。
- 吸声系数是**公开资料的典型参考值**，可逐项改写（"自定义"），不代表任何具体产品。
- **不做隔声**（邻居吵不吵你要靠墙体隔声量、撞击声、缝隙漏声，本页完全不涉及）；不推荐器材、
  不评价装修方案好坏、不做医学判定。
- 空档阈值 12 Hz、50–120 Hz 范围、拖/接近/干三档与其两条分界线，都是**本页的设计选择**，不是标准。

默认数据与 8 个内置场景**全部是虚构示例**。说明里每个数字都能回溯到同一次已验算结果
（`说明数字校验.cjs`，未登记 0 个）。
